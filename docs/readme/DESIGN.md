# README 首图设计

## 概念

用一张安装路径图表现三个工具入口如何指向一份 Skill。路径端口、汇合线和折角文件标记对应安装位置、共享内容目录以及目录中的 `SKILL.md`。候选方案还包括 CLI 输出和界面截图。CLI 输出适合演示单条命令，界面截图里的路径在手机上较难阅读。路径图突出项目如何处理多个工具入口，适合放在首屏。

## 证据

- 入口标签取自 [工具名称](../../src/core/paths.ts#L5) 和 [默认扫描目录](../../src/core/paths.ts#L33)。
- 共享目录来自 [安装计划](../../src/core/operations.ts#L355)，连线来自 [创建工具入口](../../src/core/operations.ts#L633)。
- 共享内容按 [真实路径分组](../../src/core/scanner.ts#L81)。图中的 `<name>` 代表实际安装名。

## 视觉规格

采用终端式路径标注和 Markdown 正文，首图后直达快速开始。插图使用 1200 × 400 画布，以文件标题和小尺寸路径标签形成尺度差，强调色集中在汇合后的线路。浅色像印刷文件，底纹用点阵和叠纸。深色沿用 [控制台青柠色](../../src/web/styles.css#L12)，用坐标格和角标标出文件。字体采用 Arial / Helvetica 和 Menlo / Consolas / Liberation Mono，分别回退到系统无衬线和等宽字体。

| 主题 | 背景      | 文件文字  | 路径文字  | 汇合线    |
| ---- | --------- | --------- | --------- | --------- |
| 浅色 | `#f0f2e8` | `#202b1a` | `#52604b` | `#3b5b19` |
| 深色 | `#151913` | `#edf3e6` | `#b2bea8` | `#c5f36a` |

## 渲染复核

初版从 Claude Code 端口开始使用强调色，看起来像有优先级。修订后把强调色移到汇合点和共享路径一侧，并加宽右下路径的底框。两版均在 830 px 和 360 px 下检查。桌面可读完整标签，手机保留可辨认的文件名和连线，完整路径也在正文中提供。
